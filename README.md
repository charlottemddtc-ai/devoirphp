Portfolio Personnel

Description

Portfolio web développé en PHP et MySQL permettant de présenter mon profil, mes compétences et mes projets.

Le site dispose également d’une interface d’administration pour la gestion des projets.

Technologies utilisées

PHP
MySQL
HTML5
CSS3
JavaScript
Bootstrap
Accès au site

Site web :

https://charlotteportfolio.42web.io

Accès à l’administration

Pour accéder à l’espace administrateur :

https://charlotteportfolio.42web.io/admin/connexion.php

Après authentification, l’administrateur peut :

Ajouter des projets
Modifier des projets
Supprimer des projets
Gérer le contenu affiché sur le portfolio
Dépôt GitHub

Le code source complet du projet est disponible sur ce dépôt GitHub.
